# 四十六块的三天 · 校园财商微短剧

> 第 1 课 · AI 短剧一站式制作 —— 从一句话梗概到可播放的分镜预览页

一部 **60 秒 / 8 镜 / 3 人** 的校园财商微短剧完整制作包。剧本、人物设定、分镜表、8 张分镜图、SRT 字幕、片头片尾文案、可播放的分镜预览页，全部由 **WorkBuddy 单一工具**在一条链路内完成。

## 一句话梗概

> 当苏念想请客撑面子时，却只剩四十六块撑三天，最后因室友端回一桌一元菜而作罢。

## 在线预览

- 分镜预览页：`index.html`（GitHub Pages 直达，双击 `08_分镜预览.html` 亦可离线播放）
- 深链参数：`?shot=4` 定位到第 4 镜｜`?t=32.5` 定位到第 32.5 秒｜`?play=1` 自动播放

## 预览页功能

- 片头 3 秒 → 按分镜时长逐镜轮播 → 片尾 5 秒
- 底部叠加当前镜字幕，右上角显示镜号、场景标签、剩余秒数与总进度条
- 播放 / 暂停、上一镜、下一镜、重播 4 个按钮
- 键盘：`空格` 播放暂停、`←` 上一镜、`→` 下一镜、`R` 重播
- 图片缺失时显示「本镜图片待补」占位卡，绝不出现浏览器破图
- 纯 HTML/CSS/JS 单文件，零外部依赖，移动端自适应

## 使用的能力

`WB-CHAT` 剧本写作 · `WB-FILE` 文件读写 · `WB-IMAGE` 图像生成 · `WB-HTML` 页面构建 · `WB-CMD` 校验

> **未启用**：视频生成（成片 MP4，按课程为可选加分项）、任何外部平台发布连接器。
